Лаба с процессами: Киллер и юзер 

Build:

    make

На выход имеем 3 проги: `killer`, `user`, и еще  `victim`.

Принцип:

- `victim` программа которая выводит свой ПИД и засыпает. Можно давать ей имя, имя исопльзуется в киллере.
- `killer` умеет:
  - `--id <pid>`: отсылать SIGTERM сигнал
  - `--name <procname>`: нвходить и убивать процессы по имени
  - если установлена переменная окружения `PROC_TO_KILL` как разделенный дефсиами спсиок имен,то `killer` попытается их убить при вызове 

- `user` демонстрирует использование: устанавливает `PROC_TO_KILL` в окружение, запускает жертв,  `killer` с `--name`, `--id`, чекает какие ПИДы запщены, ансетает переменную и тп

Подсказки:
- Программа написана под линух
- Возможно будут нужны разрешения
