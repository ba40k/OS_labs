# Pipe Lab - Linux версия

Это портированная версия проекта с Windows API на Linux с использованием POSIX вызовов.

## Как запустить на Linux:

### Способ 1: С использованием Makefile
```bash
make clean
make all
make run
```

### Способ 2: Ручная компиляция
```bash
g++ -std=c++11 -o M M.cpp
g++ -std=c++11 -o A A.cpp
g++ -std=c++11 -o P P.cpp
g++ -std=c++11 -o S S.cpp
g++ -std=c++11 -o Main main.cpp
./Main
```

## Описание программы:

Программа демонстрирует работу с трубами (pipes) в Linux. Главный процесс (Main) запускает несколько подпроцессов и передает данные между ними:

1. **M** - умножает каждое число на 7
2. **A** - добавляет 23 к каждому числу
3. **P** - возводит каждое число в куб (x³)
4. **S** - суммирует все числа

## Основные изменения из Windows версии:

- **CreateProcess()** → **fork()** и **execlp()**
- **CreatePipe()** → **pipe()**
- **WriteFile()** → **write()**
- **ReadFile()** → **read()**
- **WaitForSingleObject()** → **waitpid()**
- **SetHandleInformation()** → убрано (не нужно на Linux)
- Изменены имена исполняемых файлов: `M.exe` → `./M` и т.д.

## Примечания:

- Используются POSIX функции для работы с процессами и трубами
- Весь вывод автоматически перенаправляется между процессами
- Программа работает на всех POSIX-совместимых системах (Linux, macOS, BSD и т.д.)
